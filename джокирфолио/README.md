# jokerfolio — Портфолио Frontend-разработчика

Современный адаптивный сайт-портфолио frontend-разработчика, разработанный в точном соответствии с Figma Community шаблоном.

## Стек технологий
- **HTML5** (Семантическая разметка, доступность a11y)
- **CSS3** (Flexbox, CSS Grid, CSS Variables, анимации)
- **JavaScript (ES6+)** (Интерактивность, ScrollSpy, фильтрация проектов)
- **React, TypeScript, Git**

## Особенности проекта
- Фирменный купольный блок Figma Hero с прозрачным аватаром Наруто и вылетающими бейджами технологий
- Наклонная бесконечная бегущая строка с ключевыми навыками (включая MS Office и Visual Studio Code)
- Сетка карточек стека технологий с подробными списками знаний и умений
- Интерактивный таймлайн траектории профессионального роста
- Портфолио проектов с динамической фильтрацией по категориям
- Блок "Сейчас изучаю" (JavaScript, TypeScript, React)
- Прямое скачивание резюме в формате PDF в один клик
- Прямые ссылки на контакты (Telegram, Email, GitHub)
- Полная адаптивность для мобильных устройств, планшетов и десктопов
